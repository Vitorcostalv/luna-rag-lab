# Security

Do not use the demo identity selector as production authentication. Do not upload confidential data to a publicly accessible instance. Role and project filters are enforced by the backend but demonstration identities are intentionally impersonable.

Report a suspected vulnerability privately to the repository owner through GitHub rather than posting secrets in an issue. Include affected behavior and a synthetic reproduction. No paid-provider guarantee or enterprise SLA is offered.

Secrets remain in server environment variables. Retrieval is untrusted data. The planner cannot execute arbitrary SQL or call tools selected by document instructions. Quota reservations cover generation; embedding usage is recorded but embedding calls are not blocked independently. Distributed rate limiting and verified identities need additional controls before shared paid production use.
