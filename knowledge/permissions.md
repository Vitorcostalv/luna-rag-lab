# Permissões do laboratório

Admin Demo lê e escreve documentos e consulta todos os datasets do projeto demo. Analytics Demo lê documentos e consulta todos os datasets demo. Retail Demo lê documentos e consulta OTS e devices, mas não demografia. Viewer Demo lê documentos e não executa analytics.

Todos os usuários precisam de membership do projeto antes de retrieval ou consulta. Documentos de outro projeto nunca entram no contexto. Demo identity — not production authentication. O seletor de usuário é público para estudo e não oferece autenticação de produção.
