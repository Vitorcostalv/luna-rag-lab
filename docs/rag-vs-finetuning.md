# RAG vs fine-tuning

RAG fornece conhecimento externo atualizado a cada consulta, permitindo acesso por projeto e inspeção de evidências. Fine-tuning muda parâmetros do modelo para adaptar comportamento ou padrões de saída. Ele não substitui a validação de acesso, a consulta de valores atuais ou as citações.

Comece com retrieval, ferramentas e métricas claras. Fine-tuning pode ser estudado depois para necessidades de comportamento medidas em avaliações. Este laboratório não treina modelos.
