# Contributing

Use Node 22+ and pnpm. Keep all examples and fixtures synthetic; never submit client information, credentials or proprietary procedures. Add domain behavior in focused modules rather than API routes.

Before a PR run pnpm lint, pnpm typecheck, pnpm test and pnpm build. For UI changes run pnpm test:e2e. Describe observable behavior, validation and known limits. Use conventional commits. Provider tests must use mocks and consume no external API quota.
